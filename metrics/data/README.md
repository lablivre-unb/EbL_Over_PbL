# Data Folder

This directory stores the CSV outputs of the metrics pipeline.

## Structure

- `bronze/`: raw extraction output (append-only)
- `silver/`: filtered and curated output

## Expected files

- `bronze/prs.csv`: raw PR/MR metrics from the extraction script
- `silver/prs.csv`: filtered dataset produced by the filter script

## Notes

- The files are generated by `metrics/scripts/extract.py` and `metrics/scripts/filter.py`.
- If you run the scripts from a different working directory, update their input/output paths accordingly.
