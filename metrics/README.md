# Metrics

This folder contains datasets, notebooks, and scripts used to produce metrics and figures for the project.

## Structure

- data/
  - Raw and curated datasets (bronze and silver layers).
- notebooks/
  - Analysis and visualization notebooks.
- scripts/
  - Data extraction, filtering, and transformation scripts.

## Key notebooks

- notebooks/prs_viz_bp_paper.ipynb
  - Paper-ready figures and tables.
- notebooks/prs_viz_bp_analysis.ipynb
  - Additional figures not cited in the paper.
